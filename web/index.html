Fiken MCP

Et verktøy jeg har laget for å bruke Fiken fra Claude og ChatGPT i mine egne foretak. Tenkte jeg like så gjerne kunne gjøre det tilgjengelig for andre også.

GitHub

Vil du prøve?

Appen er foreløpig i utviklingsmodus hos Fiken, så det er plass til fem brukere, og jeg legger inn hver enkelt selv. Vil du prøve, send meg e-postadressen du bruker i Fiken.

Slik kommer du i gang

Du trenger:

  • tilleggstjenesten «API» i Fiken – 99 kr/mnd (Fiken MCP er gratis)
    Foretak › Tilleggstjenester › API
  • tilgang til appen (se over)
  • Claude eller ChatGPT

Claude (mobil, web og desktop)

  1. Gå til Customize › Connectors.
  2. Trykk Add og velg Add custom connector.
  3. Gi koblingen et navn, for eksempel Fiken, og lim inn denne adressen:

    https://api.fiken-mcp.byjoba.com/mcp

  4. Logg inn med Fiken når du blir bedt om det.

Claude Code

claude mcp add --transport http fiken https://api.fiken-mcp.byjoba.com/mcp

ChatGPT

Ikke testet ennå.

Hva den kan

Nesten alt i Fiken.

Ingenting kan slettes, reverseres eller annulleres. Det gjør du selv i Fiken, så en feil fra Claude eller ChatGPT alltid kan rettes opp i Fiken.

Skal Claude eller ChatGPT bare kunne lese, bruker du denne adressen i stedet:

https://api.fiken-mcp.byjoba.com/mcp/readonly

Personvern

Tjenesten lagrer ingen av dataene dine. Filer og regnskapsdata går gjennom serveren på vei til og fra Fiken, men blir verken lagret eller logget. Det samme gjelder innloggingen din hos Fiken.

Det eneste som tas vare på, er anonym bruksstatistikk: hvor mange ganger hvert verktøy er brukt per måned, og om det gikk bra. Tellingen knyttes til en kode som lages fra e-postadressen din, og koden kan ikke regnes tilbake til adressen.

Kobler du fra i Claude eller ChatGPT, glemmer bare den appen innloggingen. For å stenge tilgangen helt går du i Fiken til Rediger konto › Sikkerhet › Apper du har gitt tilgang til og fjerner tilgangen for Fiken MCP. Gjør det også hvis du tror at en enhet eller konto er på avveie.

Ansvarsfraskrivelse

Fiken MCP er noe jeg har laget på fritiden, og det har ingen tilknytning til Fiken AS. Det leveres som det er, uten noen form for garanti.

Claude og ChatGPT kan ta feil. Du er selv ansvarlig for alt som bokføres, faktureres eller sendes fra foretaket ditt, også når Claude eller ChatGPT gjør det for deg. Kontroller alltid resultatet i Fiken. Jeg er ikke ansvarlig for feil i regnskapet eller for tap som følger av at du bruker tjenesten.
